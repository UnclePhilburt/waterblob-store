Machine Steps

  1. On the Square machine, cancel/exit any normal checkout screen.
  2. Open account/settings and sign out of normal Square POS if it is signed in there.
  3. On the sign-in screen, choose device-code sign in.
  4. Generate a code here and type it into the Square machine.
  5. Refresh paired devices here. The terminal should appear with a deviceId.
  6. Make sure Render has that exact SQUARE_TERMINAL_DEVICE_ID, then redeploy/restart Render.
